# OOPS Banner App

## About the Project
The OOPS Banner App is a Java-based console application built to explore core programming fundamentals and Object-Oriented Programming (OOP) concepts. [cite_start]The project starts with a simple use case of displaying the word "OOPS" in the console and progressively refactors the code to display it in a large ASCII banner format using spaces and `*` characters[cite: 222]. 

[cite_start]As the application scales, the code is refactored to become more modular by utilizing functions, defining classes to store character patterns, and ultimately using maps to handle the display logic[cite: 222].

## Learning Objectives
[cite_start]This project is developed using a strict Gitflow branching strategy to mirror professional industry standards[cite: 14, 270]. Features are developed incrementally:
* **UC1:** Core Java syntax and printing literal text to the console.
* **UC2:** Constructing multi-line ASCII art using sequential print statements.
* **UC3:** Optimizing memory management and string concatenation using the `String.join()` method.
* **UC4:** Improving modularity and reusability by implementing String arrays and enhanced for-loops.
* **UC5:** Streamlining code conciseness through direct Array Initialization.
